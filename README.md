# مدار — مساحة عمل التسويق العربية

تطبيق عربي RTL لإدارة الحسابات والجمهور والمحتوى والحملات والفريق، مع Backend محلي وقاعدة SQLite. لا يعتمد على خدمة SaaS أو قاعدة بيانات سحابية.

## التشغيل

المتطلبات: Node.js 24 وnpm.

```bash
npm install
npm run dev
```

يشغّل هذا الأمر Vite وAPI معًا. لتغيير العنوان أو المنفذ:

```bash
npm run dev -- --host 127.0.0.1 --port 7100
```

- الواجهة: المنفذ المحدد، غالبًا 7100.
- API: `127.0.0.1:7101`، وتمرّر Vite طلبات `/api` إليه.
- قاعدة البيانات ومفتاح التشفير: `server/data/`، وهذا المجلد مستثنى من Git.

عند أول تشغيل، أنشئ حساب المدير من شاشة الإعداد. كلمات المرور تُخزّن باستخدام scrypt، والجلسات عبر cookie من نوع HttpOnly.

## بناء وتشغيل الإنتاج المحلي

```bash
npm run lint
npm run build
npm start
```

`npm start` يشغّل API ويقدّم ملفات `dist/` من الخادم نفسه. يمكن تغيير:

- `MADAR_API_HOST`: الافتراضي `127.0.0.1`، واستخدم `0.0.0.0` عند نشره على الشبكة.
- `MADAR_API_PORT`: الافتراضي `7101`.
- `MADAR_SECURE_COOKIE=true`: إلزامي عند HTTPS.
- `MADAR_ALLOWED_ORIGINS`: قائمة origins مفصولة بفواصل.
- `MADAR_DATA_DIR`: مسار قاعدة البيانات ومفتاح التشفير.
- `MADAR_TOKEN_KEY`: مفتاح AES اختياري بطول 64 محرفًا hex. إن لم يحدد، يُنشأ مفتاح محلي ويُحفظ بصلاحيات مقيّدة.

## الوظائف

- لوحة تحكم وإحصائيات ورسوم بيانية.
- حسابات تجريبية، وربط Facebook حقيقي عبر OAuth أو Access Token.
- مجموعات جهات اتصال واستيراد وتصدير CSV.
- مكتبة محتوى وحملات ومجدولة وتقارير.
- استخراج بنتائج اصطناعية واضحة، وحفظها كمجموعة جمهور.
- ردود تلقائية وصندوق وارد يحفظ مسودات فقط.
- أعضاء فريق وأدوار وسجل تدقيق وإعدادات إرسال.
- حفظ مساحة العمل في SQLite مع نسخة مساعدة في localStorage.
- بحث عام وإشعارات وحوارات وتصميم متجاوب.

**لا يوجد إرسال رسائل أو نشر أو استخراج خارجي تلقائي حتى الآن.** موصل Facebook الحالي يثبت الهوية ويجلب الصفحات ويفحص الاتصال فقط. تنفيذ الحملات الحقيقية يحتاج عامل مهام وصلاحيات إضافية وموافقة صريحة.

## ربط Facebook

راجع [دليل إعداد Facebook](FACEBOOK_SETUP.md). باختصار:

1. أدخل App ID وApp Secret والرابط العام في «الحسابات ← إضافة حساب ← ربط حساب حقيقي».
2. انسخ Valid OAuth Redirect URI إلى إعدادات Facebook Login.
3. ابدأ Facebook Login واختر الحساب والصلاحيات.
4. يمكن أيضًا التحقق من Access Token موجود دون إدخال كلمة مرور فيسبوك.

لا ترسل App Secret أو Access Token في المحادثة؛ أدخلهما في الواجهة فقط. يُخزّنان باستخدام AES-256-GCM على الخادم، ولا يعودان إلى المتصفح.

## البنية

```text
src/
  components/      الهيكل والحوارات وشاشة الدخول وموصل فيسبوك
  context/         حالة مساحة العمل والمزامنة مع API
  data/            البيانات التوضيحية
  lib/             API والتنسيق والتنزيل
  pages/           صفحات التطبيق المقسمة كوديًا
  types/           نماذج TypeScript
server/
  index.mjs        API والجلسات والملفات الثابتة
  store.mjs        SQLite والجداول والعمليات
  security.mjs     scrypt وAES-256-GCM والمفاتيح
  facebook.mjs     OAuth وGraph API والصفحات
scripts/dev.mjs    تشغيل Vite وAPI وإيقافهما معًا
```

## التحقق

- 33 اختبارًا عامًا في Chrome، بما فيها التنقل والنماذج والحفظ بعد إعادة التحميل والاستيراد والتصدير والاستجابة.
- 15 اختبارًا خاصًا بفيسبوك باستخدام محاكي Meta محلي: إعداد المدير والتطبيق وOAuth والصفحات والتحقق من الرموز ورفض غير الصالح.
- فحص تشفير قاعدة البيانات وعدم وجود رموز الوصول كنص صريح.
- فحص 375 و768 و1024 و1440 بكسل دون تمرير أفقي لكامل الصفحة.
- صفر أخطاء Console وصفر HTTP 404 في الاختبار العام.

لم يُختبر حساب Facebook حقيقي بعد؛ الاختبار الحقيقي يحتاج تطبيق Meta وحساب المستخدم وموافقته.
